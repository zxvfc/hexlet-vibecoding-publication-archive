# Архив публикаций

Архив подборок научных публикаций (arXiv) по выбранным темам.

## Структура

- `index.html` — веб-страница архива: темы, поиск, список публикаций с постраничным выводом. Открывается в браузере без сборки.
- `archive/` — сохранённые подборки публикаций.

## Добавление публикаций

Записи хранятся в массиве `PUBS` внутри `index.html` (блок «ПУБЛИКАЦИИ»). Формат записи:

```json
{
  "id": "2610.40325",
  "url": "https://arxiv.org/abs/2610.40325",
  "title_ru": "Заголовок",
  "published": "29.10.2026",
  "desc_ru": "Описание",
  "category": "Трансформеры"
}
```

Статистика сканирований — в объекте `STATS` там же.

## Как пополняется

1. Поиск новых статей на arXiv по темам.
2. Перевод названий и аннотаций на русский язык.
3. Добавление подборки в `archive/`.
4. Уведомление о новых публикациях в Telegram.
