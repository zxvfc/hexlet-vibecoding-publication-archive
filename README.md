# Архив публикаций

Архив научных публикаций с arXiv по выбранным темам. Заголовки и описания переведены на русский язык.

## Просмотр

Страница загружает данные из JSON-файлов, поэтому её нужно открывать через веб-сервер (при открытии `index.html` двойным кликом браузер не даст прочитать файлы с диска). Из корня репозитория:

```bash
python3 -m http.server
```

Затем откройте http://localhost:8000. На GitHub Pages страница работает без настройки.

На странице:

- **Темы** — список тем слева с числом публикаций; темы можно добавлять и удалять. Изменения сохраняются только в вашем браузере.
- **Поиск** — по названию, описанию, номеру arXiv, ссылке и категории.
- **Публикации** — новые сверху, по 5 записей на страницу.
- **Статистика** — число сканирований, сохранённых ссылок и время последнего сканирования.

## Структура

```
index.html               веб-страница архива
data/publications.json   публикации
data/topics.json         темы по умолчанию
data/stats.json          статистика сканирований
README.md                это описание
```

## Данные

### `data/publications.json`

Массив публикаций. Пример записи:

```json
{
  "id": "2610.40325",
  "url": "https://arxiv.org/abs/2610.40325",
  "title_ru": "Заголовок на русском",
  "published": "29.10.2026",
  "desc_ru": "Описание на русском",
  "category": "Трансформеры"
}
```

| Поле | Описание |
| --- | --- |
| `id` | Номер публикации на arXiv. Записи с повторяющимся `id` отбрасываются. |
| `url` | Ссылка на страницу публикации. |
| `title_ru` | Заголовок на русском. |
| `published` | Дата публикации в формате `ДД.ММ.ГГГГ`. |
| `desc_ru` | Краткое описание на русском. |
| `category` | Тема. Должна совпадать с названием темы на странице, иначе запись не показывается. |

Порядок записей в файле не важен: страница сортирует их по дате, новые сверху.

### `data/topics.json`

Массив названий тем, которые показываются при первом открытии страницы:

```json
["Трансформеры", "Обработка языка", "Компьютерное зрение", "Машинное обучение", "Генеративные модели"]
```

Если посетитель уже менял темы на странице, у него используется сохранённый в браузере список.

### `data/stats.json`

```json
{ "scans": 10, "lastScan": "2026-11-06T01:31:00Z" }
```

`scans` — число сканирований, `lastScan` — время последнего сканирования в формате ISO 8601 (UTC). Обновляется вместе с публикациями.

## Как пополняется архив

1. Поиск новых статей на arXiv по темам.
2. Перевод заголовков и аннотаций на русский язык.
3. Добавление записей в `data/publications.json` и обновление `data/stats.json`.
4. Уведомление о новых публикациях в Telegram.
